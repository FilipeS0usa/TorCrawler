# THE CRAWLER 
This project is for academic purposes only, I'm using to learn about new 
technologies and tecniques, just like sockets, databases, docker, docker swarm, 
api, tor network, algorithms, project management, and the list goes on. It is 
basicly a Tor Network Crawler writen in python with an SQL database. In the 
future I would like to create a browser with all the Information that I scraped 
from the Tor Network.

## Introduction
I started this project in my cybersecurity course, so I decided to continue and
use it as a learning method. It was initially just a way of learning how to 
automate scrapping the web, and ended up as crawler that scrapes the Tor 
Network for new `.onion` urls. Thus creating a database full of Tor Network 
websites making it easier for me to search the network. There was also other 
ideas that we had for exploring this database, you could automate certain 
processes so that you can find specific information that you want in the 
darkweb.

Also there can be other applications for this project that are still open for 
exploration.
